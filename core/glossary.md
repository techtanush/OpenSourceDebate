# Glossary

Debate vocabulary used in this repo. Terms vary by league; this is the common core.

| Term | Meaning |
|------|---------|
| **Card** | One piece of cited evidence: tag, cite, body. |
| **Tag** | The one-sentence claim at the top of a card. |
| **Cite** | Source information; the short cite (`Name YY`) is spoken. |
| **Cut a card** | Excerpt a source and mark what is read. |
| **Highlight / read** | The words actually spoken aloud. |
| **DOA** | Date of access: when you retrieved the source. |
| **Verbatim** | The Word template/plugin most debaters use; also: "word for word." |
| **Pocket / Hat / Block** | Top three levels of a file's outline (see `card-anatomy.md`). |
| **Case** | The constructive speech: a side's main arguments, read first. |
| **Contention** | A major argument in a case, usually with subpoints. |
| **Advantage / Disadvantage (DA)** | Good result of your plan / bad result of the other side's. |
| **Link** | Why an action causes the claimed result. |
| **Internal link** | A middle step in a causal chain. |
| **Impact** | The final harm or benefit and why it matters. |
| **Uniqueness (UQ)** | What is true now; whether the harm/benefit is already happening. |
| **Non-unique** | The claimed outcome happens either way. |
| **Turn** | Argue the opponent's evidence helps *you* (link turn / impact turn). |
| **Mitigate** | Reduce how much an argument matters. |
| **Takeout** | Fully answer an argument. |
| **Extend** | Carry an argument through the round and explain why it still stands. |
| **Drop** | An argument the other side never answered. |
| **Overview** | Opening summary of how the debate should be decided. |
| **Weighing** | Comparing impacts (probability, magnitude, timeframe, reversibility). |
| **Voting issue** | A reason the judge should vote for you. |
| **Collapse** | Narrow your speech to your best arguments. |
| **Block (A2)** | Prepared answers to a common argument ("A2" or "AT" = "answers to"). |
| **Frontline** | Prepared defense of *your own* argument against the opponent's likely responses. |
| **Rebuttal** | Speech(es) answering the opponent's case and defending yours. |
| **Cross-ex (CX) / crossfire** | Questioning period between speeches. |
| **Flow** | Notes organizing every argument made in the round. |
| **Clipping** | Claiming to read words you skipped (an integrity violation). |
| **Cutting out of context** | Marking text so the claim means something the author didn't say. |
| **WPM** | Words per minute; typical speech rates are 200-300. |
