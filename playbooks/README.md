# Playbooks

End-to-end procedures for the jobs a debater actually asks for. Each playbook says what to collect, the exact steps and commands, what files to produce, and how to know it is done. They tie together the protocols in `core/` and `speeches/`; read those for the details behind each step.

| # | Playbook | Use when |
|---|----------|----------|
| 01 | [Build a case from scratch](01-case-from-scratch.md) | A new topic: write contentions as link chains |
| 02 | [Answer an opposing case](02-answer-an-opposing-case.md) | You have their case (file or PDF) and need a rebuttal and blocks |
| 03 | [Build a blocks library](03-blocks-library.md) | Prepare answers to the arguments you expect, before the round |
| 04 | [Build frontlines for your own case](04-frontlines.md) | Defend your contentions against their likely responses |
| 05 | [Backlines, summary, and final speeches](05-backlines-and-summary.md) | Later speeches: extend, collapse, weigh |
| 06 | [Use my files as context](06-use-my-files-as-context.md) | The user already has files: index, search, reuse, match style |

**Always:** read `core/integrity.md` first, save the full text of every source, verify quotes, lint, and finish with the "Before you read these" caveats list.
