# build-backlines

First read `AGENTS.md` and `core/integrity.md` from the repo root. Never fabricate or paraphrase inside a quote.

## Read these files

- `speeches/backlines/PROTOCOL.md`
- `speeches/summary-final/PROTOCOL.md`
- `core/refutation-guide.md`
- `core/logic-flow.md`

## Playbook

`playbooks/05-backlines-and-summary.md`

## Steps

1. Get the round: what was said and which cards were read. Ask if unclear; never guess what was read.
2. For each of our rebuttal answers they responded to, state their response fairly in one sentence.
3. Write the extension: the card already read (as a short Extend), plus the one-sentence reason it beats their response. Add a new card only if the format allows it and it is needed.
4. Collapse to one or two arguments we are winning, weigh (probability, magnitude, timeframe, reversibility), and give two or three voting issues.
5. Time it with `tools/speech_timer.py` and trim the weakest extension first.

## Finish with

A short "Before you read these" list: unverified items, claimed drops that need checking against the flow, and any new card that is not verified.
