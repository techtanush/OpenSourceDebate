# write-rebuttal

First read `AGENTS.md` and `core/integrity.md` from the repo root. Never fabricate or paraphrase inside a quote, and never treat a snippet as the source text.

## Read these files

- `speeches/rebuttal/PROTOCOL.md`
- `core/integrity.md`

## Steps

1. Extract the opponent's text (PDF or .docx) and map every argument and card.
2. Find answers in order: their own evidence, no link/non-unique/no impact, turns, mitigation, source attacks.
3. Write overview, line-by-line, and weighing. Extend your own earlier cards as short analytics.
4. Time it with `tools/speech_timer.py`. Flag unverified quotes.

## Delivering files

Tell the user the .docx must be opened in CardMirror or Verbatim (Word) to show its formatting; install steps are in `docs/CARDMIRROR.md`.

## Finish with

A short "Before you read these" list: UNVERIFIED quotes, biased or weak sources, missing credentials or dates, and highlighting an opponent could attack.
